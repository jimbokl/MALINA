# МАЛИНА — КЛУБНИКА / malinaklubnika.ru

Ягодное медиа и каталог для садоводов: проверенные материалы о малине и садовой землянике, объяснимый выбор сорта, обсуждения и путь к реальному предложению. Долгосрочная идея BerryVerse включает торговлю, инструменты садовода, партнёров и профессиональные сервисы.

**Статус на 25.09.2026:** информационный сайт и журнал с 10 проверенными материалами опубликованы через GitHub Pages. Домен `malinaklubnika.ru` назначен сайту, DNS указывает на GitHub Pages, но публичная проверка HTTPS пока не проходит: сертификат не содержит домен. Модель предложений и партий реализована без фиктивных продаж; подтверждённых партнёров, собственных партий и региональных испытаний сортов пока нет. Публичная форма отзывов ждёт отдельного HTTPS API. Команда из 100 разработчиков в исходном тексте — сценарий масштаба, а не фактический ресурс.

## Сайт

Нужны Node.js 20+, Python 3 для локального сервера, Rust с целью `wasm32-unknown-unknown` и `wasm-pack` 0.13.1. Внешних npm-зависимостей нет. Сборка использует Rust CLI для выпуска проверенного JSON-каталога и Rust/WASM для регионального движка.

```bash
npm run build
npm test
npm run dev
npm run check:public
```

После запуска сайт доступен на `http://127.0.0.1:5181/`. Сборка создаёт `dist/` с самостоятельными HTML-страницами, стилями, графикой, публичным снимком каталога и WASM-модулем. Основной публичный адрес — `https://malinaklubnika.ru/` после выпуска сертификата; сборка Pages задаёт `SITE_URL=https://malinaklubnika.ru` и `SITE_BASE=/`. [GitHub Pages запрещает использовать Pages для сайтов, главным назначением которых являются коммерческие транзакции или онлайн-бизнес](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits); торговый контур потребует другого хостинга.

Главная, рубрики журнала, статьи, страницы культур, каталог, карточки сортов, справочный подбор, отзывы, руководство и описание источников доступны без JavaScript; JS нужен для фильтрации, интерактивного подбора, обмена ссылкой и приёма/показа отзывов. Содержание, факты и изображения описаны в [реестре источников](docs/SOURCES.md), редакционный выпуск и распространение — в [редакционном процессе](docs/EDITORIAL_OPERATIONS.md). `npm run check:public` читает реальный HTTPS-сайт и проверяет сертификат, robots, sitemap, canonical и базовый HTML; пока сертификат не выпущен, эта команда ожидаемо завершается ошибкой.

Страницы статей собираются в статический HTML без нового генератора. Причины выбора и условия пересмотра — в [ADR 0005](docs/adr/0005-editorial-generator.md). Партнёрские предложения и собственные партии отделены от сортов в общей SQLite; пока реальные записи не подтверждены, кнопок покупки и заявлений об остатках нет. См. [ADR 0006](docs/adr/0006-commercial-publication.md).

## Отзывы

Форма на `/otzyvy/` просит только имя или псевдоним, регион, сорт и текст. Под каждым отзывом можно ответить, указав имя, регион и текст; сорт наследуется из обсуждаемого отзыва. Ответы образуют раскрывающиеся ветки. Rust API записывает сообщения в ту же SQLite, что и каталог; JEV проверяет каждое на спам и пользу для обсуждения. Полезный опыт публикуется, явный спам и пустые реплики отклоняются, сомнительное решение или сбой JEV оставляет запись в скрытой очереди `pending_human_review`. Редактор может одобрить содержательную критику. Локально форма работает с `REVIEW_API_URL=http://127.0.0.1:8080/api/reviews`; для публичной формы нужен доступный браузеру HTTPS адрес API, поскольку GitHub Pages не исполняет серверный код. Ключ JEV остаётся только в окружении API.

Опубликованные отзывы можно выгрузить из общей базы командой `python3 db/catalog.py export-reviews --out db/public/reviews.json` и коммитить этот файл в GitHub. В нём нет черновиков и причин модерации; GitHub Pages показывает снимок при отсутствии API. См. [ADR 0004](docs/adr/0004-reviews-sql-jev.md).

## Первый рабочий шаг

Следующий шаг — выпустить HTTPS-сертификат для `malinaklubnika.ru`, затем выполнить `npm run check:public` и проверить сайт на телефоне (`W-05`). Для публичных отзывов нужен HTTPS-хост Rust API с общей SQLite. Параллельно нужны подтверждённые источники по регионам России, редакторская проверка сортов, реальные партнёры и доступ к каналам распространения. Подбор пока остаётся справочным сравнением по описаниям первоисточников, без региональных рекомендаций.
