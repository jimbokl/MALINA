## Основание решения

В [проверенной выборке Wordcraft](../research/wordstat/wordcraft-raspberry-2026-09-26/README.md) 83 из 100 строк относятся к именованным сущностям; «фото» встречается в 47, «отзывы» — в 42. Это состав выборки, не доля аудитории и не прогноз трафика. Приоритет MALINA — полноценная карточка сорта, связанная с инструментами выбора.

Запросы и метрики присланной таблицы совпали с живым отчётом по 100 строкам; совпали также 100 URL после нормализации записи адресов. Регион в интерфейсе не выбран, конкретный месяц не показан. По [справке Яндекса](https://yandex.ru/support/webmaster/ru/service/queries-selection) метрики запросов — среднемесячные за прошлый год, популярность страниц — за предыдущий месяц. Это не текущий топ по единственной фразе и не доказательство причин ранжирования.

## Что берём из рубрикатора конкурента

На [странице каталога Stroy-Podskazka](https://stroy-podskazka.ru/malina/sorta/) наблюдаются поиск по названию, алфавит, быстрые подборки, сортировки по популярности/рейтингу, режимы фотографий/характеристик, предложение отсутствующего сорта. Фильтры охватывают цвет, размер, вкус, созревание, ремонтантность, шипы, болезни, перевозку, поросль, формы роста, отзывы. Это перечень возможностей; значения свойств и чужие отзывы в MALINA не импортируются.

### Словарь будущих фильтров

Каждое поле сначала проходит проверку источника, единиц и применимости. Приоритет расширения: сроки плодоношения и возраст плодоносящих побегов; шипы и поросль; цвет и размер; вкус и плотность; условия зимовки; конкретные болезни; транспортировка. Урожайность хранить вместе с площадью/возрастом растения, агротехникой, местом и годом испытания. «До −35 °C» без условий не становится фильтром пригодности города. «Высокая устойчивость» не заменяет утверждение о конкретном патогене.

### Канонические страницы

- `/sorta/` — общая точка выбора; фильтры меняют состояние, не порождают отдельную индексируемую страницу на каждую комбинацию.
- `/sorta/{slug}/` — одна сущность: фото → характеристики/источники → рекомендация читателя → отзывы/ответы → сравнение или предложение.
- `/goroda/` → `/podbor/?city=…&region=…` → сорт с сохранённой географией → опыт рядом.
- `/rating/` — рейтинг рекомендаций с раздельным просмотром культур. Подбор по климату доступен отдельным переходом.
- Страница сравнения — следующий срез W-14. Будущий постоянный URL принимается при реализации; не создаём пустой маршрут.

Явный геоконтекст найден у восьми запросов. Геозависимость выдачи по смене региона не измерялась: `not_tested`. Для установления геозависимости нужен отдельный парный замер одних и тех же запросов при одинаковом устройстве/времени и разных регионах; название города в запросе само этого не доказывает.

## Приёмка

1. Войти по имени сорта, прочитать факты, увидеть источник и реальные отзывы на одной странице.
2. Перейти из города в подбор; контекст места не превращается в необоснованную рекомендацию.
3. Проголосовать, повторить отправку, отменить: серверный счётчик соответствует одному активному голосу. Ошибка оставляет прежнее состояние.
4. При одинаковых счётчиках место одинаковое; у нуля нет места. В рейтинге видны методика и свежесть снимка.
5. На телефоне все действия доступны без горизонтального скролла страницы. Клавиатурный фокус и состояние кнопки различимы.

Визуальные концепции: [design/references](../design/references/README.md). Это исследовательские макеты; они не являются свидетельством наличия свойств, фото сортов, голосов или опубликованных функций.
