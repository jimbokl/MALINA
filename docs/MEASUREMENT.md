В Метрике созданы пять JS-целей с точным совпадением идентификатора: `article_to_cultivar`, `selector_complete`, `selector_no_region_data`, `review_submitted`, `affiliate_click`. Для отправленного отзыва передаются только вид сообщения и состояние публикации. Метод `reachGoal` требует заведённую JS-цель; [документация](https://yandex.ru/support/metrica/en/objects/reachgoal). Следующий шаг измерения — проверить появление конверсий в интерфейсе после реальных действий. Сайт и отдельный API не должны передавать в аналитику имя, введённый пользователем регион, текст отзыва, телефон, IP или ключ JEV.

Фиксировать каждую неделю дату, источники данных, значения и изменение по сравнению с предыдущей неделей. После четырёх полных недель установить цели роста по реальному базовому уровню. При смене домена/хостинга сохранять URL и настройки измерения, сверить канонические адреса, sitemap и цели.
