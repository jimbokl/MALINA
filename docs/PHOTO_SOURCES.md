# Реальные фотографии сортов: источники и проверка

Проверено 25.09.2026 для задачи `F-03`/`D-05`. Цель — заменить иллюстрацию в карточке сорта только фотографией с **двумя независимыми подтверждениями**: право использовать файл на коммерческом сайте и обоснованная привязка изображённого растения к названному сорту. Название в поисковой выдаче, подпись продавца или визуальное сходство сами по себе не доказывают сортовую идентичность.

## Где искать

| Источник | Права | Пригодность для карточки сорта |
| --- | --- | --- |
| [Wikimedia Commons](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia) | Проверять **страницу каждого файла**: автора, лицензию, ссылку на неё и требования к указанию изменений. CC BY и CC BY-SA допускают коммерческое использование при соблюдении условий. | Первый выбор для поиска подписанных сортов, но подпись загружающего всё равно требует редакторской оценки. |
| [PxHere](https://pxhere.com/en/faq) | Сайт заявляет CC0 для своих изображений; права третьих лиц могут сохраняться. | Для общих материалов о ягодах. У найденных общих фото нет подтверждения конкретного сорта. |
| [Public Domain Pictures](https://www.publicdomainpictures.net/en/terms-of-service.php) | Лицензия указана **на странице файла**, обычно CC0; партнёрские стоки имеют отдельные условия. | Для общих материалов после проверки страницы файла; не считать сорт доказанным по ключевым словам. |
| [Pakutaso](https://www.pakutaso.com/en/userpolicy.html) | Бесплатное коммерческое использование в пределах собственных условий, **не CC0**; есть требование возможности общаться с сервисом на японском. | Пока не найдено оснований применять для сортовых карточек. |
| [Bugwood Images](https://video.bugwood.org/support/FAQ.cfm) | Личное/образовательное использование разрешено с указанием автора; для коммерческого использования требуется разрешение фотографа, даже если оно без оплаты. | Возможен точный агрономический снимок после отдельного разрешения. |
| Питомники, лаборатории, RHS и фотостоки | Видимый файл или кнопка скачивания не дают автоматически право публикации. Проверять условия или получать письменное разрешение/лицензию. | Хороший путь для редких сортов и проверяемого происхождения растений. |

Кандидаты для будущего расширения каталога: [«Зенга Зенгана» (Senga Sengana)](https://commons.wikimedia.org/wiki/File:Fragaria_ananassa_Senga_Sengana_2023-06-12_7456.jpg), 3019×2264, и [«Хоней» (Honeoye)](https://commons.wikimedia.org/wiki/File:Fragaria_ananassa_Honeoye_2023-06-02_6832.jpg), 2936×2202. Обе фотографии опубликованы автором Salicyna под CC BY-SA 4.0; на страницах файлов указаны сорта. Русское название «Хоней» встречается в [публикации РАН](https://new.ras.ru/upload/iblock/d42/gzswnfho5hi90vv8ozkns2wpuygwhe1h.pdf). Это кандидаты для редакторской проверки, но не независимое подтверждение генетической идентичности растений. Если сорта будут добавлены и фото приняты, указывать автора, страницу файла, лицензию и сделанные изменения; при адаптации изображений соблюдать ShareAlike для адаптаций.

## Запись для каждого опубликованного фото

`cultivar_id`, URL страницы файла, URL исходного файла, автор/правообладатель, лицензия и ссылка на неё **или** сохранённое разрешение, область разрешённого использования, источник атрибуции сорта, дата проверки, редакторский статус, текст подписи/атрибуции, список изменений (например, кадрирование), версия оптимизированного файла. Хранить исходное доказательство прав так, чтобы оно оставалось доступным после изменения внешней страницы. Без подтверждённого права файл не публиковать. Если право подтверждено, но сортовая идентичность неизвестна, фото допустимо только как иллюстрация культуры с соответствующей подписью, без имени сорта в `alt`.
