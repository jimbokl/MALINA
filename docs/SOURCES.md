Для материала [«Как выбрать сорт клубники»](../site/editorial.mjs) 26.09.2026 повторно проверены руководство RHS по типам садовой земляники и [Penn State Extension: сорта для домашнего сада](https://extension.psu.edu/strawberry-varieties-for-home-gardens). Penn State описывает результаты и устойчивость сортов для Пенсильвании и соседних штатов; эти данные не используются как рекомендации для России. Источники помогают объяснить признаки для сравнения, но российская региональная пригодность текущих карточек остаётся неизвестной.

Публичные названия сортов даны кириллицей. Исходные международные написания сохранены рядом с первоисточником для идентификации сорта. В переданной владельцем [выгрузке запросов по сортам](../research/keyword-variety-queries-2026-09-24.tsv) есть запросы «малина полька» и «клубника элан»; для «Джоан Джей» и «Кембридж Фаворит» частоты в этой выгрузке не подтверждены. Выгрузка помогает выбрать темы, но не доказывает свойства сортов или пригодность для региона.

## Лабораторное размножение

Для публичной страницы In Vitro использовано первичное исследование [Quiroz и соавт., 2017, meristem culture and micropropagation of Chilean strawberry](https://www.scielo.cl/pdf/bres/v50/0716-9760-bres-s40659-017-0125-8.pdf). Оно описывает меристемную культуру, размножение, адаптацию вне культуры и вирусное тестирование. Исследована чилийская земляника (*Fragaria chiloensis*), поэтому конкретные результаты и проценты нельзя переносить на любой сорт садовой земляники (*Fragaria × ananassa*) или на любую лабораторию.

Предоставленный владельцем каталог Клубничной фермы Борисовых «Осень 2026» (редакция 15.07.2026) хранится только в `knowledge/private/`. Это источник сведений **о предложении продавца**, а не независимая проверка фитосанитарного статуса, сортовой идентичности или урожайности. Публичные цены и наличие из него не публикуются.

`berries-hero.webp`, `raspberry-garden.webp` и `strawberry-garden.webp` созданы генератором изображений OpenAI для этого проекта 24.09.2026. Их используют только как иллюстрации культур. Они не являются фотографиями конкретных сортов, посадочного материала или местного питомника. Оригиналы генерации сохранены в локальной истории Codex; оптимизированные версии находятся в `site/assets/`.

Источники реальных фотографий сортов, лицензии и кандидаты для замены иллюстраций: [PHOTO_SOURCES.md](PHOTO_SOURCES.md). На 26.09.2026 проверенные сортовые фотографии для восьми карточек не одобрены к публикации.
