# ADR 0002 — статический сайт первой демонстрационной версии

Статус: **принято для локальной демонстрационной версии**. Дата: 24.09.2026. Связано с `W-01`–`W-05` и `F-04`.

## Контекст

Нужен работающий сайт MALINA сейчас. Подтверждённых продавцов, товаров, региональных сортовых испытаний, редакторской команды и доступа к домену пока нет. Публичные страницы должны давать полезный HTML без JavaScript. Интерактивному фильтру не нужны персональные данные или сервер.

## Варианты

1. Статическая генерация HTML из небольшого проверяемого файла данных.
2. Серверный сайт с БД и редакторским кабинетом.
3. Клиентское SPA, которое строит содержимое после загрузки JavaScript.

## Решение

Для первого демонстрационного среза выбран вариант 1: Node.js собирает страницы в `dist`, каталог и подбор работают в браузере. Источники, ограничения и дата просмотра видны в HTML. Данные посетителей не отправляются на сервер. Дальнейший Rust/WASM-контур и GitHub Pages закреплены в [ADR 0003](0003-rust-wasm-github-pages.md).

## Последствия

В каталоге только четыре записи; нет редакторского рабочего процесса, региональных рекомендаций, продавцов и заказов. Обновления требуют правки данных и повторной сборки. ADR 0001 о полноценной архитектуре продукта остаётся открытым.

## Пересмотр

Перейти к серверной публикации и БД, когда появятся регулярные обновления данных, редакторский процесс, проверенные предложения или иная измеренная необходимость. Публичный HTML и происхождение фактов сохранить.
