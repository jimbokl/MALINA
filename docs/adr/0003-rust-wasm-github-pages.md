# ADR 0003 — Rust, WASM и бесплатная статическая публикация

Статус: **принято**. Дата: 24.09.2026. Связано с F-04, F-05, D-01, D-02, W-03.

## Контекст

Владелец выбрал Rust + WASM и бесплатный GitHub-хостинг, хочет основу для большого продукта. Первое публичное содержимое — справочник, без проверенных продавцов, цен и заказов. GitHub Pages отдаёт статические файлы; серверные Rust-процессы и SQLite на нём не выполняются. [Условия GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits) также исключают сайты, предназначенные главным образом для коммерческих транзакций и онлайн-бизнеса.

## Решение

- Rust CLI (`crates/catalog_tool`) ведёт SQLite-миграции, проверяет целостность и при сборке выпускает публичный JSON только из проверенных записей.
- Rust/WASM (`crates/selector`) выполняет в браузере объяснимые региональные правила над публичным снимком. При отсутствии проверенного правила результат пустой.
- Статический генератор выпускает HTML для поисковых систем; GitHub Pages размещает информационный прототип. Книги и рабочая БД остаются локальными и исключены из Git.
- Сущности данных и контракты остаются пригодны для последующего серверного каталога и торгового контура. Коммерцию размещать на сервисе, который её допускает, после появления реальных предложений и операционного процесса.

## Последствия и пересмотр

CI должен проверять Rust, WASM, миграции и статические страницы. Домена нет в конфигурации Pages, пока DNS и его проверка не завершены. Региональные рекомендации, платёжные операции, личные данные и актуальные остатки пока не включаются. Пересмотреть хостинг перед публикацией коммерческого сценария или при необходимости серверных функций.
