# ADR 0005 — генератор редакционного HTML

Статус: принят 25.09.2026 для текущего выпуска. Связано с `F-04`, `W-09`.

## Контекст

MALINA уже собирает статический HTML для каталога, подбора и материалов через `site/scripts/build.mjs`. Пользователь предложил рассмотреть Zola для статей. [Zola](https://www.getzola.org/documentation/getting-started/overview/) действительно поддерживает Markdown, шаблоны страниц/разделов и статическую публикацию. Существующий HTML также статический, поэтому само название генератора не определяет скорость чтения или позиции поиска.

## Решение

Доделать единые редакционные шаблоны в текущей сборке. Rust остаётся источником публичного каталога, Rust/WASM — инструментом интерактивного подбора. Не вводить второй генератор одновременно с первым редакционным выпуском: это добавит дублирование роутинга, метаданных и интеграции каталога без известного выигрыша для читателя.

## Пересмотр

Проверить после первых материалов: время подготовки и проверки статьи, читаемость шаблонов, количество ручных ошибок в источниках/медиа, длительность CI, размер страниц и полевые Core Web Vitals. Если текущая сборка мешает регулярной работе редактора или имеет измеримый предел, сделать отдельный прототип Zola на одной статье, сохранить URL и семантический HTML и сравнить результаты. Оценку PageSpeed 100/100 заранее не обещать.
