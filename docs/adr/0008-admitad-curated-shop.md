# Магазин с отбором товаров Admitad

## Решение

`/magazin/` — статическая витрина товаров малины и клубники без повторов. Постоянный реестр `site/shop-catalog.json` хранит все 298 строк фида с ID, названием и категорией. Строки одной культуры с одинаковым нормализованным названием, включая варианты фасовки и метку ASF, объединяются в 160 публичных карточек и страниц `/magazin/<slug>/`. Ещё 138 адресов вариантов перенаправляют на основную страницу и не входят в каталог и sitemap. Доступный артикул группы используется для заказа через её основную страницу. Тексты шести ранее подготовленных страниц остаются в `site/shop-products.mjs`; для остальных используется краткое описание позиции без неподтверждённых агрономических свойств. Наборы, альпийская земляника и гибриды показываются под своим названием, а не выдаются за саженец одного сорта. Для каталога формируется `CollectionPage` с `ItemList`, для доступного товара — `Product` с `Offer`; у страниц есть собственные title, description и хлебные крошки.

Текущий заказ оформляется на сайте продавца. Кнопка использует партнёрский URL Admitad и помечена `rel="sponsored nofollow noopener noreferrer"`. Сорт, редакционный текст и товарное предложение остаются разными сущностями. Внутренней оплаты и обещания собственного остатка здесь нет.

## Данные и обновление

`site/scripts/admitad-feed.mjs` получает CSV из HTTPS URL в секрете Actions `ADMITAD_FEED_URL`. Скрипт выбирает ID постоянного реестра, проверяет культуру и название, а для доступных позиций — рублёвую цену и связку tracking URL с адресом продавца. Снимок включает также позиции `out_of_stock`; у них нет цены и кнопки заказа. Снимок живёт не более 36 часов. При ошибке обновления или просрочке сборка сохраняет все страницы, но убирает цену и кнопку заказа. Товарные фотографии по возможности загружаются в локальный каталог сборки; если загрузка не удалась, допустим проверенный адрес изображения продавца или нейтральная иллюстрация культуры.

Объединение опирается на культуру и название товара после удаления явных меток фасовки и ASF; для «Вима Кимберли» и повторной «Изобильной» есть отдельно проверенные соответствия. Похожие названия и одинаковые описания сами по себе не служат основанием: продавец повторяет один текст и у разных сортов. Разные сорта и наборы сохраняют собственные страницы.

Workflow `.github/workflows/pages.yml` обновляет снимок перед каждой публикацией и по расписанию раз в сутки. Секретный URL и сам снимок в Git не попадают. Реестр создан из CSV от 28.09.2026 командой `node site/scripts/generate-shop-catalog.mjs <feed.csv>`: 298 строк, 160 товаров после объединения, из них 22 группы доступны и 138 недоступны на дату проверки. Последующие обновления наличия не меняют число страниц. Для локального прогона с фидом достаточно задать `ADMITAD_FEED_URL` в окружении, выполнить `node site/scripts/admitad-feed.mjs`, затем `SITE_URL=https://malinaklubnika.ru npm run build` и `SITE_URL=https://malinaklubnika.ru npm test`.

## Расширение ассортимента

Новый товар добавляется после проверки ID, категории и названия в фиде через обновление постоянного реестра. Существенные агрономические утверждения публикуются только при наличии проверенных источников; данные предложения сами по себе такими источниками не считаются. URL товара остаётся стабильным при смене цены и наличия. При добавлении другого продавца нужно расширить явно разрешённые домены в проверках фида и публичной модели, а также текст продавца в карточке предложения.
