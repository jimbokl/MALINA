# Магазин с отбором товаров Admitad

## Решение

`/magazin/` — статическая витрина карточек. Каждый товар из `site/shop-products.mjs` имеет отдельный постоянный адрес `/magazin/<slug>/`. HTML содержит описание сорта, подходящие регионы по опубликованным допускам, шаги посадки, источники и ссылку на страницу сорта с отзывами. Для каталога формируется `CollectionPage` с `ItemList`, для доступного товара — `Product` с `Offer`; у страниц есть собственные title, description, canonical и хлебные крошки.

Текущий заказ оформляется на сайте продавца. Кнопка использует партнёрский URL Admitad и помечена `rel="sponsored nofollow noopener noreferrer"`. Сорт, редакционный текст и товарное предложение остаются разными сущностями. Внутренней оплаты и обещания собственного остатка здесь нет.

## Данные и обновление

`site/scripts/admitad-feed.mjs` получает CSV из HTTPS URL в секрете Actions `ADMITAD_FEED_URL`. Скрипт выбирает только заранее сопоставленные ID, проверяет культуру, название сорта, наличие, рублёвую цену и связку tracking URL с адресом продавца. Снимок предложения живёт не более 36 часов. При ошибке обновления или просрочке сборка сохраняет описательные страницы, но убирает цену и кнопку заказа. Товарные фотографии загружаются в локальный каталог сборки; если загрузка не удалась, используется подписанная иллюстрация соответствующего сорта из существующего атласа.

Workflow `.github/workflows/pages.yml` обновляет снимок перед каждой публикацией и по расписанию раз в сутки. Секретный URL и сам снимок в Git не попадают. Для локального прогона с фидом достаточно задать `ADMITAD_FEED_URL` в окружении, выполнить `node site/scripts/admitad-feed.mjs`, затем `SITE_URL=https://malinaklubnika.ru npm run build` и `SITE_URL=https://malinaklubnika.ru npm test`.

## Расширение ассортимента

Новый товар добавляется только после проверки ID и сорта в фиде, российской опоры для существенных агрономических утверждений и отдельного редакционного описания в `site/shop-products.mjs`. URL товара остаётся стабильным при смене цены, наличия или продавца. При добавлении другого продавца нужно расширить явно разрешённые домены в проверках фида и публичной модели, а также текст продавца в карточке предложения.
