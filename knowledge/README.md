# Внутренняя библиотека MALINA

Четыре предоставленные владельцем книги хранятся локально в `knowledge/private/library/originals/`. Их Markdown-копии и изображения находятся в `knowledge/private/library/markdown/`, исходные имена и SHA-256 — в закрытом `knowledge/private/library/manifest.json`. Вся папка `knowledge/private/` исключена из Git и публичного сайта.

| ID | Источник | Формат | Назначение |
| --- | --- | --- | --- |
| `kazakov_remontant_russia` | И. В. Казаков, А. И. Сидельников, В. В. Степанов, «Ремонтантная малина в России» | DOC → DOCX → Markdown | Термины ремонтантности, выращивания и сортов |
| `sagirova_pribaikalye` | Р. А. Сагирова и соавторы, «Ремонтантная малина в Предбайкалье» | PDF → Markdown | Региональный исследовательский контекст |
| `zhvakin_berries_2015` | В. Жвакин, «Виноград, малина, смородина, крыжовник и другие ягоды» | FB2 → Markdown | Разделы по ягодным культурам |
| `kazakov_kichina_malina_1980` | И. В. Казаков, В. В. Кичина, «Малина» | DjVu → OCR → Markdown | Историческая терминология и агротехника |

Это рабочие копии для внутреннего анализа. Автоматическое извлечение может менять порядок таблиц, подписи и знаки. Перед использованием утверждения сверяйте страницу или раздел с оригиналом; старые или региональные наблюдения не переносите на всю Россию. Медицинские утверждения не входят в садовый тезаурус.

Структура терминов и порядок редакторской проверки описаны в [THESAURUS.md](THESAURUS.md). Конвертер DOCX и FB2: `scripts/convert_library.py`; метаданные качества PDF и DjVu лежат рядом с их Markdown-файлами в закрытой папке.
