# «Боровицкая» в подмосковном запросе: наблюдение без регионального правила

- Задачи: D-03, D-04, D-06.
- Проверка первичного источника: 27.09.2026.
- Данные: `db/migrations/0047_borovitskaya_moscow_study_observation.sql`.

## Почему этот сценарий

В [замере Яндекс Wordstat](../wordstat/INTENTS-GEO-AND-DEMAND-2026-09.md) фраза «сорта клубники для Подмосковья» получила 2 956 запросов за 24.08–22.09.2026 по всем регионам и устройствам. Это сигнал спроса на региональный выбор, а не число потенциальных посетителей и не доказательство пригодности сорта. «Боровицкая» уже опубликована в каталоге по описанию ФНЦ Садоводства (`0037`), поэтому дополнительный измеренный результат расширяет существующую карточку.

## Что говорит первичная публикация

[В. Г. Толстогузова, «Хозяйственно-биологическая оценка интродуцированных сортов земляники в Московской области», ВНИИСПК, 2008](https://vniispk.ru/pages/activities/science-activities/conference-2008/publ-2008-25). В абзаце, начинающемся словами «Фактическая урожайность лучших сортов...» непосредственно перед таблицей, автор перечисляет «Боровицкую» среди десяти сортов с высокой **фактической** урожайностью: **140 ц/га в среднем за два года плодоношения**. Не смешивать этот показатель с упомянутой отдельно потенциальной биологической урожайностью. Общая методика статьи говорит об изучении 60 сортов в 2004–2007 годах; отдельные годовые показатели «Боровицкой» не приведены.

| Поле | Решение |
| --- | --- |
| Объект | Уже опубликованный сорт «Боровицкая»; наблюдение `yield`, 140 ц/га. |
| Место | Заголовок сообщает о Московской области, но точный адрес участка не назван; `region_id = NULL`. |
| Период | Среднее за два года плодоношения; именно для этой строки годы не указаны. `observed_on` и даты в паспорте остаются `NULL`. |
| Метод и условия | В статье названы программы сортоизучения и традиционная технология; число повторностей не сообщено. |
| Применимость | Только измеренный результат публикации с явным контекстом и ограничениями. |

В таблице той же статьи есть другие сорта, но «Боровицкой» там нет. Поэтому для неё нельзя восстановить значения по каждому году или относительное положение в каждый сезон. Миграция не создаёт рекомендацию для Московской области, Москвы или другого региона и не меняет запись Госреестра. Для локального правила нужен источник, позволяющий привязать результат к однозначному участку и условиям.
