Проверено 28.09.2026. Задача `G-01` продолжает уже работающий `W-25`: текущий `/instrumenty/kalendar-uhoda/` даёт один следующий шаг по выбранной фазе растения, а журнал подставляет фактические даты посадки и сбора. Курганский филиал [прямо указывает](https://rosselhoscenter.ru/ob-uchrezhdenii/filialy/uralskiy/kurganskaya-oblast/na-zametku-sadovodu/), что погода существенно меняется по годам и календарную работу клубники нужно привязывать к фенологическим фазам. Поэтому месяц подходит для навигации («какие работы обычно искать весной/осенью»), а карточка действия должна сообщать проверяемый сигнал: «почки ещё не распустились», «сбор завершён», «розетка укоренилась», «есть прогноз заморозка».

## Что добавить к текущему сценарию

1. Вверху дать три понятных действия: **«Когда сажать»**, **«Когда обрезать»**, **«Когда собирать»**. За ними — культура, простой ответ и только затем уточнение типа малины/клубники. Существующая форма «Что сейчас с растением?» остаётся для сценария «Что делать сейчас».
2. Ответ каждой работы: *ориентир сезона или местное окно при наличии источника → признак готовности → действие → ссылка на первоисточник → переход к посадке, схеме обрезки, сбору или записи фактической даты*. Месячная сетка — навигация, не единственный источник решения.
3. Структурировать событие как `crop`, `task`, `cultivarType`, `trigger`, `monthHint`, `regionScope`, `sourceUrl`, `reviewedAt`, `nextToolUrl`. Для общих событий `monthHint` может отсутствовать; дата региона не распространяется автоматически на все города. Журнал хранит фактические даты отдельно от типовых подсказок.
4. В каталоге/подборе связывать известный тип плодоношения с календарём, чтобы не спрашивать его повторно; неизвестный тип не превращать в предположение. Город можно передавать через существующий slug, но окно публиковать только при подходящем проверенном региональном основании.

## Проверки для реализации

- Весна: у нераспустившейся малины доступен сценарий посадки; после распускания почек ранневесеннее окно не предлагается как «ещё успеваете».
- Летняя малина после сбора сохраняет молодые побеги. Ремонтантная с режимом двух урожаев не получает полной обрезки; неизвестный тип не получает необратимого действия.
- Однократная клубника после окончания сбора получает осмотр листьев; длительно плодоносящая с новыми цветками не переводится в послесборовую фазу.
- Показанные для Кургана/Омска месяцы не появляются в Москве, Ставрополе или неопределённом регионе. Изменение города не меняет фактические записи журнала.
- На узком экране пользователь за один переход получает ответ на выбранный вопрос и может открыть основание; при отключённом JS виден содержательный текст о посадке, обрезке и сборе с переходами к инструментам.
